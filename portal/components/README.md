# components/

Reusable, campaign-agnostic UI components, grouped by concern:

- `story/` — narrative presentation (e.g. Story Panel)
- `activities/` — activity cards and activity-type renderers
- `navigation/` — navigation and routing UI
- `rewards/` — reward popups, badges, progress
- `ui/` — generic shared UI (modals, notifications, panels)

Components receive data from the rendering engine; they never hardcode campaign content.
