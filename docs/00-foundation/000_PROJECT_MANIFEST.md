# Purpose

The authoritative entry point for the Explorer Academy repository. Every human and AI contributor should begin here.

## What is Explorer Academy?

Explorer Academy is a documentation-first educational platform that develops lifelong curiosity through immersive adventures. Adventure is the visible product; education is the hidden implementation.

## Repository Philosophy

1. Documentation is the source of truth.
2. Architecture before implementation.
3. Explicit decisions over assumptions.
4. Modular, reusable campaigns.
5. Curiosity before instruction.
